# SynapseOntology
2025 Fall term Graduation Project #2


## 1. 프로젝트 개요

사용자가 논문 파일을 업로드하면 LLM을 활용해 텍스트를 분석하고 온톨로지를 자동 구축하여 시각화 및 OWL, RDF, XML 파일 다운로드가 가능한 웹 서비스를 개발합니다.
